# Findy 요리 및 상황별 추천 가이드 문서

## 1. 문서 목적

이 문서는 사용자가 특정 요리, 상황, 시간대, 기분, 목적을 말했을 때 챗봇이 어떤 상품군을 추천해야 하는지 정의한다.

챗봇은 사용자의 요청에서 다음 정보를 추론한다.

* 만들고 싶은 요리
* 필요한 필수 재료
* 있으면 좋은 추가 재료
* 함께 먹으면 좋은 상품
* 상황에 맞는 간편 대체 상품
* 추천에서 제외해야 할 상품

---

## 2. 요리별 추천 가이드

## 2.1 카레

사용자 표현:

* "카레 만들 건데 뭐 사야 해?"
* "카레 재료 추천해줘"
* "카레 해 먹을 거야"
* "카레랑 같이 먹을 거 추천"

필수 재료:

* 카레가루
* 감자
* 당근
* 양파
* 고기류

선택 재료:

* 닭고기
* 돼지고기
* 소고기
* 버섯
* 브로콜리
* 우유
* 버터

함께 추천:

* 즉석밥
* 김치
* 단무지
* 샐러드
* 탄산음료

간편 대체:

* 즉석 카레
* 컵밥 카레
* 레토르트 카레

추천 응답 예시:

"카레를 만들 거라면 카레가루, 감자, 당근, 양파, 고기류를 먼저 추천드릴게요. 밥이 없다면 즉석밥도 같이 담으면 좋아요."

## 2.5 라면

* "라면이랑 같이 먹을 거"

* "라면 토핑 추천"
* "야식으로 라면 먹을 건데"

기본 추천:

* 라면
* 컵라면
* 계란
* 치즈
* 김치

추가 토핑:

* 만두
* 햄
* 소시지
* 대파
* 떡
* 참치
* 우유

상황별 조합:

* 매운 라면 완화: 우유, 치즈, 계란
* 든든하게: 즉석밥, 만두, 햄
* 얼큰하게: 김치, 대파, 청양고추
* 간단하게: 컵라면, 삼각김밥, 김밥류

추천 응답 예시:

"라면이랑 같이 먹기 좋은 건 계란, 치즈, 김치, 즉석밥이에요. 든든하게 먹고 싶으면 만두도 같이 추천드릴게요."

* 우유, 과일, 시리얼, 요거트, 샌드위치 중심

## 6. 추천 실패 시 대체 전략

상품 검색 결과가 비어 있으면 다음 순서로 대체 추천한다.

1. 요리명 → 핵심 재료로 재검색

    * 카레 → 카레가루, 감자, 당근, 양파
    * 김치찌개 → 김치, 두부, 돼지고기, 참치
    * 파스타 → 파스타면, 소스, 베이컨

2. 상황어 → 대표 카테고리로 재검색

    * 야식 → 라면, 만두, 피자, 떡볶이
    * 아침 → 우유, 요거트, 바나나, 시리얼
    * 피크닉 → 샌드위치, 과일, 음료, 물티슈

3. 맛 표현 → 관련 상품군으로 재검색

    * 짭짤한 것 → 감자칩, 나초, 팝콘
    * 달달한 것 → 초콜릿, 쿠키, 젤리
    * 매운 것 → 라면, 떡볶이, 매운 과자

4. 그래도 없으면 비슷한 상품 안내

    * "정확히 일치하는 상품은 찾지 못했지만, 비슷한 상품을 추천드릴게요."

## 7. 최종 응답 형식 예시

상품 추천 응답은 다음 구조를 권장한다.

1. 사용자의 의도 확인
2. 추천 상품 3개 제안
3. 짧은 추천 이유
4. 필요 시 추가 선택지 제안

예시:

"짭짤한 과자를 찾으시는 거라면 감자칩, 나초, 팝콘류를 먼저 추천드릴게요. 바삭하고 간단히 먹기 좋아서 간식이나 야식으로 잘 어울려요."

"카레 재료로는 카레가루, 감자, 당근, 양파, 고기류를 추천드릴게요. 밥이 없다면 즉석밥도 같이 담으면 좋아요."

"아침 대용으로는 우유, 요거트, 바나나, 시리얼류를 추천드릴게요. 바로 먹기 좋아서 바쁜 아침에 잘 맞아요."
