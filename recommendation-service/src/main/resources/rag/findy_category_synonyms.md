# Findy 카테고리 및 동의어 매핑 문서

## 1. 문서 목적

이 문서는 사용자의 자연어 표현을 Findy 상품 카테고리 또는 검색 키워드로 변환하기 위한 RAG 지식 문서이다.

사용자는 DB에 저장된 정확한 카테고리명을 사용하지 않을 수 있다.
따라서 챗봇은 사용자의 표현을 아래 동의어, 유사어, 상황어를 기준으로 해석해야 한다.

---

## 2. 매핑 기본 원칙

1. 사용자가 말한 단어를 그대로 먼저 검색한다.
2. 검색 결과가 부족하면 동의어로 확장한다.
3. 그래도 부족하면 상위 카테고리로 확장한다.
4. 사용자가 상황을 말한 경우, 상황별 대표 카테고리로 변환한다.
5. 사용자가 맛/감각을 말한 경우, 해당 맛과 자주 연결되는 카테고리로 변환한다.

## 7. 애매한 요청 처리

사용자가 "먹을 거 추천해줘"처럼 애매하게 요청하면 다음 순서로 추천한다.

1. 시간대가 아침이면 아침 대용 상품
2. 시간대가 점심/저녁이면 간편식 또는 식사류
3. 밤이면 야식류
4. 시간 정보가 없으면 인기 상품 또는 간식류
5. 사용자 구매 이력이 있으면 자주 구매한 카테고리 우선

응답 예시:

"간단히 먹을 걸 찾으시는 걸로 보고, 바로 먹기 좋은 간편식 위주로 추천드릴게요."

"간식류를 찾으시는 걸로 보고, 과자와 음료 위주로 먼저 추천드릴게요."
